# 5-merge-conflicts

This repository introduces merge conflicts and how to resolve them.

## Objectives

* Create a branch
* Edit a shared file
* Open a Pull Request
* Resolve a merge conflict
* Complete the Pull Request

## Files

* `story.txt`

## Task

1. Switch to the `starting-point` branch.
2. Create a new branch named `student/<your-name>`.
3. Edit the `TREASURE:` line in `story.txt`.
4. Commit your changes.
5. Push your branch to GitHub.
6. Open a Pull Request targeting `main`.
7. Resolve the merge conflict.
8. Commit the resolved file.
9. Push your changes.
10. Merge the Pull Request.

By the end of this exercise, you will have resolved your first merge conflict and completed the full GitHub workflow for handling conflicting changes.
